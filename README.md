## Selected Projects

### Pnlwise

AI-assisted P&L reporting SaaS that processes CSV, XLSX, and supported text-based PDF transaction exports. It combines deterministic rules with AI-assisted categorization, routes uncertain transactions for review, calculates P&L totals in application logic, verifies Paddle payments, and exports PDF, XLSX, and CSV.

**Stack:** Next.js, React, TypeScript, OpenAI API, Cloudflare Workers, D1, Paddle

**Live:** [pnlwise.com](https://pnlwise.com)

**Repository:** [Dmitrii-front/pnlwise](https://github.com/Dmitrii-front/pnlwise)
